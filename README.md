# N11 TalentHub E-Commerce Project

Fullstack e-commerce application built with Spring Boot microservices and React.js.

## Tech Stack
- **Backend:** Java 21, Spring Boot 3.x, PostgreSQL, JWT
- **Frontend:** React 18, Vite, Tailwind CSS
- **Infrastructure:** Docker Compose, Redis

## Microservices
| Service | Port | Description |
|---------|------|-------------|
| auth-service | 8081 | JWT Authentication |
| product-service | 8082 | Product CRUD |
| cart-service | 8083 | Cart Management |
| order-service | 8084 | Orders & Payment |

## Getting Started
```bash
docker-compose up -d
```
